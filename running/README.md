# Running

Private, single-user marathon-training PWA (front end only). The backend is the
`running-coach` Cloudflare Worker in `Bobby-zs-lo/Running-with-Claude`
(design spec: `docs/superpowers/specs/2026-10-04-running-coach-design.md`, sections 4.6 and 5).

**Hidden:** not linked from the site, `noindex,nofollow`, `Disallow: /running/` in
`robots.txt`. The page is an empty shell; all data comes from the Worker after login.

## Files

| Path | What |
|---|---|
| `index.html`, `manifest.webmanifest` | Shell, PWA metadata, SW registration |
| `sw.js` | Module service worker: shell precache, offline API copies, push, notification actions |
| `css/running.css` | Portfolio tokens, light + dark themes |
| `js/config.js` | `API_BASE` (fill in at setup) and `APP_VERSION` (bump on every deploy: it names the SW cache) |
| `js/app.js` | Shell: header, tab bar, offline badge, routing |
| `js/api.js`, `js/store.js` | Fetch wrapper (bearer token, 401 → login), in-memory cache |
| `js/router.js`, `js/format.js`, `js/markdown.js`, `js/sparkline.js`, `js/changes.js`, `js/dom.js` | Pure helpers (tested) |
| `js/push.js` | Notification permission and Web Push subscription |
| `js/views/*.js` | login, today, week, plan, health, reviews, settings |
| `assets/` | Icons, generated by `node running/tools/make-icons.mjs` |
| `tests/` | Node unit tests, Playwright smoke test, fixtures |

## Service worker and `API_BASE`

`sw.js` is registered with `{ type: 'module' }` (Chrome and Android Chrome 91+) and does
`import { API_BASE } from './js/config.js'`, so the Worker URL lives in one file. Chrome
also checks imported modules for updates, so editing `config.js` updates the SW.

## Tests

```sh
bash running/tests/run-all.sh            # unit tests (node 22)
PLAYWRIGHT_NODE_MODULES=/path/to/node_modules SHOTS_DIR=/tmp/shots \
  bash running/tests/run-all.sh --smoke  # + browser smoke test, mocked API
```

The smoke test serves the repo root, mocks the API with `page.route` using
`tests/fixtures/*.json` (rebuild with `node running/tests/fixtures/build-fixtures.mjs`), and saves
screenshots. Playwright is not a dependency of this repo. Install it somewhere else.
Set `REAL_FONTS=1` to load Google Fonts for screenshots.
